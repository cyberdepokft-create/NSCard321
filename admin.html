GitHub + Netlify szinkron

Itt adod meg, melyik repó gyökerében lévő catalog.json fájlt frissítse az admin. A teljes webshop gyökérszintű fájlstruktúrára van átalakítva. A Netlify build beállításait ez a csomag már előre megadja a netlify.toml fájlban, de a biztos main branch-es induláshoz az alábbi 1-klikkes Netlify linket érdemes használni. Az élő szinkron ettől függetlenül a GitHub-on frissített catalog.json fájlt is közvetlenül olvassa. A Build Hook továbbra is opcionális.

A sima Netlify Git-import űrlapon a Branch to deploy mezőt a repó önmagában nem tudja kötelezően kitölteni. Ez a gomb a hivatalos Netlify start/deploy linket nyitja meg, ami a megadott branch-et (alapból main) és a base directory-t (.) előre beállítja.
Automatikus, profibb mód: Netlify-ban állítsd be a GITHUB_TOKEN, GITHUB_OWNER, GITHUB_REPO környezeti változókat (opcionálisan GITHUB_BRANCH, GITHUB_PATH, NETLIFY_BUILD_HOOK). Így mentéskor az admin külön gombnyomás nélkül próbálja publikálni a katalógust.
