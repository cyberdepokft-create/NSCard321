    GitHub kapcsolat

    A termékek és a képek a GitHubon tárolódnak, a webshop onnan olvassa őket. A publikáláshoz egy hozzáférési token kell, amit csak ez a böngésző tárol.

    Haladó: tároló helye

    Ha itt módosítasz, a webshop sync-config.json fájljában is ugyanezt kell beállítani, különben a vásárlók a régi helyről olvasnak.

    Token készítése

    1. GitHubon: Settings → Developer settings → Fine-grained tokens → Generate new token.
    2. Név: NS Card admin, lejárat: amennyi kényelmes (pl. 1 év).
    3. Repository access: Only select repositories → nscardshoop.
    4. Permissions → Repository permissions → Contents: Read and write.
    5. A kapott tokent másold be balra, és mentsd el.
